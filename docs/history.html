History

Beginnings

LOUIS started as an attempt to create an artificial intelligence by modeling the human brain into a database. This initial approach was based on semantic networks with spread activation, which turned out to be a reinvention of existing concepts.

Memory Development

The focus shifted to using the semantic network as a memory backend for AI. This phase included adding a chat interface, CLI commands, and a graph view for visualizing the memory.

OpenClaw and Token Efficiency

While testing OpenClaw, the main issues were its token inefficiency and lack of Linux support for voice interactions. This led to the decision to develop LOUIS into a full-fledged AI assistant with Mistral API integration and a focus on reducing token usage.

Current State

LOUIS now features a custom interaction loop, modular capabilities, and efficient memory management. It is designed to be a lightweight, token-efficient alternative to other agent frameworks.

Capabilities

LOUIS uses a modular approach with "capabilities," which are markdown files containing usage information about different tools and workflows. These capabilities are only injected into context when the user's message contains their name, reducing token usage significantly.

How Capabilities Work

Capabilities are stored as markdown files in the capabilities directory. They are dynamically loaded and only included in the context when relevant to the task, ensuring efficient token usage. Every capability is available as soon as its corresponding file is placed in the directory.

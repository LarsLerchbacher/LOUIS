What is LOUIS?

LOUIS is an experiment to create a custom, token-efficient agent, building upon the current generation of LLMs combined with the power of semantic networks with spread activation, as well as the very helpful Open WebUI.

Key Features

  • Semantic Memory: Uses a semantic network with spread activation for memory retrieval and storage.
  • Token Efficiency: Designed to minimize token usage compared to other agent frameworks.
  • Custom Interaction Loop: A unique loop that allows for dynamic tool use and user interaction.
  • Capabilities: Modular markdown-based capabilities that reduce context bloat.

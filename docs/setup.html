Setup Guide

Prerequisites

  • Python 3.8 or higher
  • Virtual environment (recommended)
  • API key for Mistral AI

Installation

  1. Clone the repository: 
    git clone https://github.com/LarsLerchbacher/LOUIS.git
  2. Navigate to the project directory: 
    cd LOUIS
  3. Create a virtual environment: 
    python -m venv venv
  4. Activate the virtual environment: 
    source venv/bin/activate
  5. Install the required dependencies: 
    pip install -r requirements.txt

OpenWebUI

If you want to use OpenWebUI to interact with LOUIS (recommend) you have to do the following:

  1. Run an Open WebUI server.
  2. Add an OpenAI provider connection pointing to the LOUIS server at port 8000.
  3. Disable all OpenWebUI features like Tools, WebSearch, Memory and notes for the LOUIS model, as it can't use them.
  4. Optionally, upload the LOUIS.png picture from this repo as the models Profile picture

Configuration

LOUIS uses the following directory structure for configuration and data:

  • Configuration Directory: ~/.config/louis/
    • config.json: Contains API keys and general settings.
    • IDENTITY.md: Defines the personality of LOUIS. If not found, a default personality is used.
    • SOUL.md: Overrides the general behavioral instructions (system prompt).
  • Data Directory: ~/.local/share/louis/
    • capabilities/: Contains markdown files for capabilities.
    • database.sqlite: The semantic network database.
    • graph.html: Visual representation of the semantic network.
  • State Directory: ~/.local/state/louis/
    • logs/: Log files.
    • sessions/: Transcripts of the last 20 sessions.

Example config.json

{
    "name": "LOUIS",
    "username": "Lars",
    "graph-model": "mistral-medium-2508",
    "chat-model": "devstral-2512",
    "mistral_api_key": "your_mistral_api_key_here",
    "temperature": 1.0,
    "request_delay_ms": 1250,
    "context_window": 131072,
    "context_warn_percentage": 90,
    "openwebui_url": "https://10.0.0.30",
    "openwebui_ca_cert": "/usr/local/share/ca-certificates/lerchbacher-software.crt",
    "openwebui_token": "your_openwebui_token_here"
}

Notes

  • The input-tokens, completion-tokens, and other counter fields are automatically managed by LOUIS.
  • The last_summary field is used for session summaries.
  • The context_window field defines the maximum context window size (default: 131072).
  • The context_warn_percentage field sets the percentage of the context window at which a warning is issued (default: 90).
